# Privacy Policy

**Last Updated:** August 24, 2026

AetherAC ("we", "our", "us") is committed to protecting your privacy. This Privacy Policy explains how we collect, use, and safeguard information when you use our anti-cheat software and related services.

---

## 1. Information We Collect

### 1.1 When You Purchase a License

When you purchase a license for AetherAC, we collect:

| Data | Purpose |
|------|---------|
| Email address | License delivery and support |
| Payment information | Processed by our payment processor (we do not store credit card details) |
| Server IP address | License validation and fraud prevention |
| Purchase date and order ID | License management |
| Your name (optional) | Personalizing communications |

### 1.2 When You Use AetherAC

AetherAC collects minimal telemetry to ensure the software functions correctly:

| Data | Purpose |
|------|---------|
| Server software and version (e.g., Paper 1.21.1) | Compatibility tracking |
| AetherAC version | Update management and bug reporting |
| License key validation requests | Anti-piracy enforcement |
| Anonymous crash reports (if enabled) | Bug fixes and stability improvements |

### 1.3 What We DO NOT Collect

- Player usernames or UUIDs
- Player IP addresses
- Player chat messages
- Player movement data (beyond aggregated detection statistics)
- Server files, configurations, or plugin lists
- Personal data of players on your server

---

## 2. How We Use Your Information

We use the collected data for:

| Use | Data Used |
|-----|-----------|
| License activation and validation | Email, License key, Server IP |
| Customer support | Email, Purchase history |
| Software updates and security patches | AetherAC version, Server version |
| Fraud and abuse prevention | License key, Server IP, Usage patterns |
| Product improvement (aggregated) | Anonymous crash reports, Version usage |

## 3. Data Sharing

We do **not** sell, rent, or trade your personal information.

We share data only with:

| Third Party | Purpose | Data Shared |
|-------------|---------|-------------|
| Payment Processor | Processing purchases | Payment details (not stored by us) |
| Hosting Provider | Website and API hosting | Website usage data |
| Email Service | License delivery and support communications | Email address |

All third parties are contractually obligated to protect your data and use it only for the specified purposes.

---

## 4. Data Retention

| Data | Retention Period |
|------|------------------|
| License records | Duration of your license + 3 years (for audit purposes) |
| Email communications | 2 years after last contact |
| Crash reports | 30 days (anonymous) |
| Payment information | Not stored by us (handled by payment processor) |

You may request deletion of your personal data at any time by contacting us at [contact@abnt.it](mailto:contact@abnt.it).

## 5. Security

We take reasonable measures to protect your information:

- All data encrypted in transit (HTTPS/TLS)
- License validation uses secure API calls
- Payment processing handled by PCI-DSS compliant providers
- Minimal data collection reduces exposure

However, no method of transmission over the internet is 100% secure. We cannot guarantee absolute security.

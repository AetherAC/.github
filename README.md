# AetherAC Community Health Files

This repository contains the community health files for the AetherAC organization.

## What's Here

| File | Purpose |
|------|---------|
| `CODE_OF_CONDUCT.md` | Community standards and enforcement |
| `CONTRIBUTING.md` | Guidelines for contributors |
| `FUNDING.yml` | Funding and sponsorship configuration |
| `GOVERNANCE.md` | Project governance and decision-making |
| `SECURITY.md` | Security vulnerability reporting |
| `SUPPORT.md` | Where and how to get help |
| `ISSUE_TEMPLATE/` | Issue templates for bug reports and feature requests |

## These Files Apply To

- [AetherAC/anticheat](https://github.com/AetherAC/anticheat) - Private
- [AetherAC/research](https://github.com/AetherAC/research) - Private
- [AetherAC/issue](https://github.com/AetherAC/issue) - Public

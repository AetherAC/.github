## Reporting Issues

1. **Check existing issues** — Your problem might already be solved
2. **Use the issue template** — It helps us help you faster
3. **Include details** — Server version, AetherAC version, logs, steps to reproduce

## Security Vulnerabilities

**Do not report security issues in public issues.**

See our [Security Policy](SECURITY.md) for details.
